# Ukrán–orosz frontvonal – magyar interaktív térkép

Ez a repository a VladislavPrimakov/graphs nyílt forráskódú projekt magyar lokalizált, automatikusan publikált változatát készíti el.

A publikált térkép célja, hogy ugyanazon az interaktív térképen mutassa:
- a DeepState szerinti ukrán helyzetértékelést;
- a LostArmour szerinti orosz helyzetértékelést;
- a két értékelés közötti eltérően megítélt területeket.

A forrásgeometria nincs átértelmezve. A repository build közben letölti az upstream projekt aktuális verzióját, hozzáadja a magyar lokalizációt, majd GitHub Pagesre telepíti.

## Források
- DeepStateMAP: https://deepstatemap.live/
- LostArmour: https://lostarmour.info/map
- Upstream projekt: https://github.com/VladislavPrimakov/graphs
